# Data

No raw third-party audio is stored in the GitHub repository.

This directory is reserved for:

- manifest schemas;
- deterministic manifest builders;
- source metadata;
- hashes or stable source row IDs;
- train/evaluation exclusion reports.

Local corpora and common audio formats are ignored by `.gitignore`. See
[`DATA_PROVENANCE.md`](../DATA_PROVENANCE.md) and the
[artifact publication plan](../docs/artifact-publication-plan.md) before
redistributing any dataset artifact.
