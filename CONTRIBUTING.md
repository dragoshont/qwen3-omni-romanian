# Contributing

The most useful contribution is one that **tests a claim**.

Good issues/PRs include:
- reproduction with exact versions
- counterexamples to the Mimi compatibility hypothesis
- Talker/MTP label-alignment audits
- alternative low-VRAM recipes
- Romanian datasets with clear provenance
- independent evaluation scripts
- native Romanian listening evaluations
- reproducible failure cases

Please distinguish observed result, inference, hypothesis and external-source claim.

Do not upload copyrighted audiobooks/books, proprietary datasets, base-model weights or credentials.
